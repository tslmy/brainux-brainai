# Importing the explainer into the Astro blog

`brainai-how-it-works.md` is the interactive article as a post for the
author's Astro blog (the one with margin sidenotes). It is generated by
`docs/src/build.mjs` from the same source as `docs/index.html`; its body is
plain HTML (MathML for the maths, the blog's own sidenote markup), so the
blog's Markdown pipeline passes it through unchanged.

To publish it on the blog:

1. Copy `docs/assets/explainer.css` and `docs/assets/explainer.js` to the
   blog's `public/brainai/`.
2. Copy `brainai-how-it-works.md` to the blog's `src/content/posts/`.
3. `pnpm build` as usual.

The post uses the blog's colour tokens and sidenote styles; `explainer.css`
only adds the figures, tooltips and maths layout.
